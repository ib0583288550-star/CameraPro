# Camera Pro
אפליקציית מצלמה מתקדמת לאנדרואיד מבית y.b apps.

- צילום תמונות באיכות גבוהה באמצעות CameraX.
- מיקוד אוטומטי בנגיעה באזור הרצוי בתצוגה.
- מחוון חשיפה להבהרה ולהכהיה של התמונה.
- זום, פלאש והחלפה בין מצלמה קדמית לאחורית.
- בחירת תיקיית שמירה בזיכרון הפנימי או בכרטיס SD.
- ממשק כהה בעברית מלאה ובכיווניות RTL.

בנייה: `gradle assembleDebug`.
